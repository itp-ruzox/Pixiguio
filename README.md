> #### ⚡ Welcome to **Pixiguio OS** – A highly animated, futuristic GUI-based Linux OS designed for **all Raspberry Pi boards**. Inspired by Iron Man’s J.A.R.V.I.S, styled with **dichromatic neon themes**, and built for performance, style, and smart interaction.

---

## **Highlights**  

### **[SYSTEM UI]**
- **Iron Man’s JARVIS-styled interface**
- Dichromatic UI: **Blue-Green**, **Purple-Pink-Red**, **Green-Yellow**, and more
- Semi-Customizable Panels, Central AI Assistant, Real-Time System Monitors
- Neon pulse hover animations + transparent panels

---

### **[FEATURES]**
- **Tint2 panel**: Lightweight & customizable top-bar
- **AI Assistant (top-right corner)**:
  - Auto-responds on hover
  - Voice toggle: Male / Female
  - Speed control & preset commands
- **Left sidebar**: Recent apps, auto-adjusts to screen size
- **Top bar**: Boot time, date & time, CPU/RAM/Storage meter
- **Bottom dock**: AI controls and shortcuts
- **Right activity feed**: Movies, texts, system logs, recent events
- **Bottom right logs**: One-tap access to logs (search/filter)

---

### **[THEMES + BOOT ANIMATIONS]**
- Multiple **themes pre-installed**, including:
  - Blue-Green (default), Purple-Red, Green-Yellow, etc.
- **3 Boot animations included** (neon ripple, matrix wave, clean tech)
- Additional boot animations available via **Marketplace**

---

### **[BUILT-IN SOFTWARE]**
- **Lightweight Web Browser**
- **PixiEdit** – Lightweight text editor
- **CodeSpark IDE** – Minimal yet powerful code IDE
- **PixiTheme Control** – Wallpaper, Theme, Boot Animation manager
- **GUI WiFi Tool** – Easy wireless control
- **WiFi Hacking Tool** *(Educational use only)* – For ethical testing

---

### **[APP STORE + MARKETPLACE]**
- Built-in **Pixiguio App Store**
- Explore:
  - Themes
  - Animations
  - Plugins
  - Community projects
- Fully integrated with **GitHub & Dev Community**

---

### **[VOICE + AI]**
- Lightweight integrated voice recognition
- Basic AI commands for assistant
- Voice responses:
  - **Jarvis (Male)**
  - **Nova (Female)**
- Toggle voice type & control response speed

## **Installation**
**Raspberry Pi Compatible** – Zero 2W, 3B+, 4, 5 and more.

1. Flash Pixiguio OS to your SD card using **Raspberry Pi Imager** / **Balena Etcher**
2. Boot into magic – **Jarvis awakens.**
